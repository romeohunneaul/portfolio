I am building a small ecosystem of skills, frameworks and tools to ship faster without
shipping sloppier. Everything goes through GitHub, because that is where the code ships:
notes, briefs, specs, issues and pull requests live next to it.

<DeliveryPipeline />

## Why GitHub is the rail

A synthesis that lives in one tool, a spec in another and the tickets in a third drift
apart within a week. When every artefact is a file or an issue in the same place as the
code, an agent can read the whole chain, and so can I.
